# 六维力传感器上位机 (CAN)

基于 **PySide6 + pyqtgraph** 的 Windows 上位机，配合 **周立功 USBCAN-I/II** 使用，
接收板卡 CAN 数据并实时绘制六维力曲线。

## 协议约定（与板卡一致）

| CAN ID | 内容                      | 字节布局（小端 float32）       |
|--------|---------------------------|--------------------------------|
| 0x101  | 发送：FX、FY              | data[0:4]=FX, data[4:8]=FY     |
| 0x102  | 发送：FZ、TX              | data[0:4]=FZ, data[4:8]=TX     |
| 0x103  | 发送：TY、TZ              | data[0:4]=TY, data[4:8]=TZ     |
| 0x201  | 接收（上位机 -> 设备）    | 触发设备发送上述三帧六维力数据 |

例：0x101 帧数据 `11 22 33 44 55 66 77 88`，则 FX = `0x44332211`，FY = `0x88776655`（均为小端 float32）。

## 环境准备

1. 安装 Python 3.9+（64 位）
2. 安装依赖：

   ```
   pip install -r requirements.txt
   ```

3. 安装周立功 USB-CAN 驱动，并将 **ControlCAN.dll** 放到本目录
   （或放到系统 PATH，或在界面里手动选择 dll 路径）
   > dll 位数必须与 Python 位数一致（都是 64 位或都是 32 位）

## 运行

```
python main.py
```

## 使用步骤

1. **接口**选择 `ZLG USB-CAN`；若没有硬件，可选 `模拟模式` 直接看演示曲线
2. 点击 **扫描设备**，确认驱动识别到 USB-CAN 适配器
3. 选择设备类型（USBCAN-I / USBCAN-II）、设备索引、CAN 通道、波特率（默认 **500 kbps**，与板卡一致）
4. 点击 **连接**
5. 在 **指令发送** 区编辑 0x201 帧的 8 字节数据（默认全 0），点击 **发送**
   （或勾选 **周期发送** 自动定时下发）
6. 板卡回传 0x101/0x102/0x103 后，曲线与数据表格实时刷新

## 文件结构

```
host_tool/
├── main.py          # 入口
├── config.py        # 协议配置：CAN ID、字段布局、波特率表（改协议只动这里）
├── can_engine.py    # ZLG ControlCAN.dll 封装 + 模拟引擎
├── data_parser.py   # CAN 帧 -> 六维力解析（小端 float32）
├── main_window.py   # 主窗口：连接/指令/曲线/表格
└── requirements.txt
```

## 常见问题

- **加载 ControlCAN.dll 失败**：确认已装驱动，dll 位数与 Python 一致
- **打开设备失败**：换设备类型试（USBCAN-I 选 I，USBCAN-II 选 II），或增大设备索引
- **收不到数据**：核对波特率是否与板卡一致（500k），检查 CAN_H/CAN_L 接线，检查板卡是否在收到 0x201 后回传
- **曲线不平滑**：模拟数据会按正弦变化；真实数据曲线波形取决于传感器输出频率
